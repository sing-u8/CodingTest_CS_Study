## 5. Java 문제별 복습 포인트

### 5.1 [괄호 회전하기](https://school.programmers.co.kr/learn/courses/30/lessons/76502)

풀이 전에 말할 것:

```text
각 회전 위치를 시작점으로 길이 n만큼 검사한다.
여는 괄호는 push하고, 닫는 괄호는 빈 스택과 짝을 확인한 뒤 pop한다.
검사가 끝났을 때 스택이 비어 있어야 한다.
```

확인 항목:

- [ ] 홀수 길이는 즉시 `0`으로 처리할 수 있다.
- [ ] `s + s`에서 시작점 `x`부터 길이 `n`만큼 검사했다.
- [ ] `peek()` 전에 `isEmpty()`를 확인했다.
- [ ] 시간복잡도 `O(N²)`를 설명할 수 있다.

### 5.2 [주식가격](https://school.programmers.co.kr/learn/courses/30/lessons/42584)

풀이 전에 말할 것:

```text
스택에는 아직 가격 하락 시점을 만나지 못한 인덱스를 저장한다.
현재 가격이 더 낮으면 스택에서 꺼내 현재 인덱스와의 차이를 답으로 기록한다.
끝까지 남은 인덱스는 마지막 시점까지의 거리를 기록한다.
```

확인 항목:

- [ ] 값이 아니라 인덱스를 스택에 넣었다.
- [ ] 하락 조건을 `prices[stack.peek()] > prices[i]`로 작성했다.
- [ ] 같은 가격은 하락으로 처리하지 않았다.
- [ ] 모든 인덱스가 최대 한 번 push·pop되므로 `O(N)`임을 설명했다.

### 5.3 [게임 맵 최단거리](https://school.programmers.co.kr/learn/courses/30/lessons/1844)

풀이 전에 말할 것:

```text
모든 이동 비용이 1인 격자의 최단거리이므로 BFS를 사용한다.
BFS는 시작점에서 가까운 거리 순서대로 탐색하므로 목적지에 처음 도달한 거리가 최단이다.
중복 삽입을 막기 위해 큐에 넣는 순간 방문 처리한다.
```

확인 항목:

- [ ] `ArrayDeque`를 큐로 사용했다.
- [ ] 시작 위치의 거리를 `1`로 처리했다.
- [ ] 좌표 경계 → 벽 → 방문 여부 순서로 확인했다.
- [ ] 큐에 삽입할 때 방문 처리했다.
- [ ] 도착할 수 없으면 `-1`을 반환했다.

주의: 저장소의 기존 `Solution.java`는 기본 `solution()`이 효율성 0점으로 기록된 DFS를 호출한다. 오늘은 그 코드를 고쳐 외우는 것이 아니라, 빈 화면에서 BFS 풀이 한 버전을 새로 작성한다.

### 6.1 [대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/151139)

결과 한 행:

```text
2022년 8~10월 전체 대여 횟수가 5회 이상인 차량 하나의 특정 월 대여 횟수
```

핵심 단계:

1. 8~10월 전체 기간에서 대여가 5회 이상인 `CAR_ID`를 먼저 선정한다.
2. 원본 대여 기록을 같은 기간으로 다시 제한한다.
3. 선정된 차량만 `MONTH`, `CAR_ID`로 집계한다.
4. 월별 기록이 0건인 행은 출력하지 않는다.

반례:

- 한 달 대여는 5회 미만이지만 8~10월 전체 대여가 5회 이상인 차량
- 기간 밖 기록까지 합치면 5회가 되는 차량

### 6.2 [상품을 구매한 회원 비율 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/131534)

결과 한 행:

```text
특정 연·월에 상품을 구매한 2021년 가입 회원 수와 전체 2021년 가입자 대비 비율
```

핵심 단계:

1. 2021년 가입자 수를 고정 분모로 구한다.
2. 2021년 가입 회원의 판매 기록만 남긴다.
3. 연·월별 구매 회원을 `COUNT(DISTINCT USER_ID)`로 센다.
4. 고정 분모로 나누고 소수 첫째 자리까지 반올림한다.

반례:

- 같은 회원이 같은 달에 여러 상품을 구매한 경우
- 2021년 가입자가 여러 달에 반복 구매한 경우

### 6.3 [특정 기간동안 대여 가능한 자동차들의 대여비용 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/157339)

결과 한 행:

```text
2022년 11월 한 달간 빌릴 수 있고, 30일 할인 금액 조건을 만족하는 자동차 한 대
```

날짜 겹침 공식:

```text
기존 대여 시작일 <= 요청 종료일
AND 기존 대여 종료일 >= 요청 시작일
```

겹치는 기록이 하나라도 있는 자동차를 제외한다. `NOT IN`을 사용하려면 서브쿼리의 `CAR_ID`가 `NULL`이 될 수 없는지 확인하고, 확신이 없다면 `NOT EXISTS`를 우선한다.

반례:

- 기존 대여 종료일이 `2022-11-01`인 경우
- 기존 대여 시작일이 `2022-11-30`인 경우
- 11월과 전혀 겹치지 않는 10월·12월 기록
- 같은 차에 겹치는 기록과 겹치지 않는 기록이 함께 있는 경우

## 7. 시작 전 백지 템플릿

아래 코드를 읽고 베끼지 말고, 빈 파일에서 필요한 형태만 재현한다.

### `ArrayDeque` 스택

```java
Deque<Integer> stack = new ArrayDeque<>();

stack.push(value);
int top = stack.peek();
int removed = stack.pop();
boolean empty = stack.isEmpty();
```

### `ArrayDeque` BFS 큐

```java
Deque<int[]> queue = new ArrayDeque<>();
queue.offer(new int[]{0, 0});

while (!queue.isEmpty()) {
    int[] current = queue.poll();
}
```
